예제9-14 Date 객체 메소드

날짜 및 시간 생성, 읽기, 형식 출력

현재 날짜와 시간

Date의 getFullYear(), getMonth(), getDate(), getDay(), getHours() 등을 확인합니다. getMonth()는 0부터 시작하므로 표시할 때 1을 더합니다.

핵심 코드

const now = new Date();
now.getFullYear();
now.getMonth() + 1;
now.getDate();
now.getDay();
now.getHours();
now.getMinutes();
now.getSeconds();
