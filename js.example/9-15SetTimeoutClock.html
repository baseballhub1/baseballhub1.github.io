예제9-15 setTimeout으로 현재 시간 갱신

setTimeout을 반복 호출하여 1초마다 시계 업데이트

실시간 시계

한 번 실행되는 setTimeout 내부에서 다시 setTimeout을 예약하여 시간을 주기적으로 갱신합니다. 실제 실행 간격은 브라우저 상태에 따라 달라질 수 있습니다.

핵심 코드

function tick() {
  document.querySelector("#clock").textContent =
    new Date().toLocaleTimeString("ko-KR");
  timer = setTimeout(tick, 1000);
}
tick();
