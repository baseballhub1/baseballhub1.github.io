예제9-16 Array 메소드

배열의 추가, 삭제, 변환, 정렬, 검색

배열 메서드 실행

push, pop, unshift, shift, slice, splice, includes, map, filter, sort, join 등을 실습합니다.

핵심 코드

const a = [3, 1, 4, 2];
a.push(5);
a.pop();
a.map(x => x * 2);
a.filter(x => x > 2);
a.sort((x, y) => x - y);

sort는 기본적으로 문자열 기준으로 비교하므로 숫자 정렬에는 비교 함수를 사용하는 것이 좋습니다.
