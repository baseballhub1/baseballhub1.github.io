예제9-17 로또(Lotto) 게임

중복 없는 숫자 6개를 무작위로 뽑는 예제

로또 번호 추첨

1~45에서 중복 없이 6개를 뽑아 오름차순으로 출력합니다. 학습용 예제이며 실제 복권 구매나 당첨을 보장하지 않습니다.

핵심 코드

const numbers = new Set();
while (numbers.size < 6) {
  numbers.add(Math.floor(Math.random() * 45) + 1);
}
const result = [...numbers].sort((a, b) => a - b);

Set은 중복된 값을 허용하지 않아 서로 다른 숫자 6개를 얻을 수 있습니다.
