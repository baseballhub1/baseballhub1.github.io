예제9-1 객체

객체 리터럴의 속성과 메서드

핵심 설명

객체 리터럴은 중괄호로 정의합니다. 점 표기법과 대괄호 표기법으로 속성에 접근합니다.

JavaScript 예제 코드

const student = {
  name: '철수',
  age: 21,
  major: 'AI소프트웨어',
  introduce() {
    return this.name + ' / ' + this.major;
  }
};
console.log(student.name);
console.log(student['age']);
console.log(student.introduce());
student.age = 22;
console.log(student.age);
