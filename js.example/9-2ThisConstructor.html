예제9-2 this 객체 생성자

this를 이용한 인스턴스 생성

핵심 설명

new와 함께 호출한 생성자 함수 내부의 this는 새로 만들어지는 객체를 가리킵니다.

JavaScript 예제 코드

function Car(brand, year) {
  this.brand = brand;
  this.year = year;
  this.info = function () {
    return this.brand + ' (' + this.year + ')';
  };
}
const a = new Car('현대', 2026);
const b = new Car('기아', 2025);
console.log(a.info());
console.log(b.info());
console.log(a instanceof Car);
