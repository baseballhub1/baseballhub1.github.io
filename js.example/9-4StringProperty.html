예제9-4 String 속성

String.length 알아보기

핵심 설명

length는 공백을 포함한 문자열의 UTF-16 코드 단위 수이며, 함수가 아닌 속성이므로 괄호 없이 사용합니다.

JavaScript 예제 코드

const text = 'Hello World';
console.log('문자열:', text);
console.log('길이:', text.length);
console.log('공백 포함 길이:', 'A B'.length);
console.log('빈 문자열 길이:', ''.length);
