예제9-5 String 메소드1

문자열 찾기와 추출

핵심 설명

검색 메서드는 위치나 포함 여부를 알려 주고, 추출 메서드는 새 문자열을 반환합니다.

JavaScript 예제 코드

const text = 'JavaScript Study';
console.log('charAt(0):', text.charAt(0));
console.log('indexOf(Script):', text.indexOf('Script'));
console.log('includes(Study):', text.includes('Study'));
console.log('slice(0, 4):', text.slice(0, 4));
console.log('substring(4, 10):', text.substring(4, 10));
console.log('startsWith(Java):', text.startsWith('Java'));
