예제9-6 String 메소드2

문자열 변환과 분리

핵심 설명

문자열은 원시 값으로 수정할 수 없습니다. 대다수 문자열 메서드는 원본을 변경하지 않고 새 값을 반환합니다.

JavaScript 예제 코드

const text = '  Hello JavaScript  ';
console.log('trim:', text.trim());
console.log('toUpperCase:', text.toUpperCase());
console.log('toLowerCase:', text.toLowerCase());
console.log('replace:', text.replace('JavaScript', 'Git'));
console.log('split:', 'apple,banana,grape'.split(','));
console.log('repeat:', 'Hi'.repeat(3));
console.log('원본:', text);
