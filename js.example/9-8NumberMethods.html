예제9-8 Number 메소드

숫자 형식 변환과 판별

핵심 설명

toFixed·toPrecision·toExponential은 문자열을 반환합니다. Number.isNaN은 NaN만 판별합니다.

JavaScript 예제 코드

const n = 1234.5678;
console.log('toFixed(2):', n.toFixed(2));
console.log('toPrecision(5):', n.toPrecision(5));
console.log('toExponential(2):', n.toExponential(2));
console.log('toString(16):', (255).toString(16));
console.log('Number.isInteger(3):', Number.isInteger(3));
console.log('Number.isNaN(NaN):', Number.isNaN(NaN));
console.log('Number.parseInt(12px):', Number.parseInt('12px', 10));
console.log('Number.parseFloat(3.14kg):', Number.parseFloat('3.14kg'));
