입력값을 바꾸면 결과가 갱신됩니다

직접 값 바꿔보기

기존 첫 두 예제는 x=1, y=3을, 세 번째 예제는 x=1.234를 사용합니다. 각 예제의 값을 따로 변경할 수 있습니다.

acos·asin의 정의역은 -1~1, acosh는 1 이상입니다. 유효하지 않은 입력에는 NaN이 나타날 수 있습니다. Math.random()은 값을 다시 계산할 때마다 달라집니다.

JavaScript 코드 예시

// x와 y 값으로 계산
const x = 1;
const y = 3;

console.log(Math.abs(x));       // 절댓값
console.log(Math.atan2(x, y));  // 두 값으로 각도 계산
console.log(Math.max(x, 3, 0.3, 12));
console.log(Math.pow(x, y));

const z = 1.234;
console.log(Math.round(z));     // 반올림
console.log(Math.sqrt(z));      // 제곱근
console.log(Math.trunc(z));     // 소수 부분 제거

Math 메서드 대부분은 숫자를 받고 숫자를 반환합니다. 삼각함수는 각도를 라디안으로 다룹니다.
