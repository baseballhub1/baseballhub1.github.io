String 속성 통합

문자열과 length 속성

핵심 설명

문자열의 대표적인 속성은 length이며 UTF-16 코드 단위의 개수를 반환합니다.

JavaScript 예제 코드

const str = 'JavaScript';
console.log('원본:', str);
console.log('length:', str.length);
console.log('첫 문자:', str[0]);
console.log('마지막 문자:', str[str.length - 1]);
console.log('String 객체:', new String('Hello').length);
