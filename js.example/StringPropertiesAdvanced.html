String 속성 응용

문자열 길이 응용 및 입력 검사

핵심 설명

length를 조건 검사에 사용할 수 있습니다. 일부 이모지는 한 글자처럼 보이지만 length가 2 이상일 수 있습니다.

JavaScript 예제 코드

const password = 'abc12345';
console.log('입력 길이:', password.length);
console.log('8자 이상:', password.length >= 8);
const msg = '안녕하세요';
console.log('글자 수:', msg.length);
const emoji = '😀';
console.log('이모지 length:', emoji.length);
console.log('유니코드 문자 수:', Array.from(emoji).length);
