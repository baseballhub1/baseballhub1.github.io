이벤트 함수

버튼의 click 이벤트에 함수를 연결합니다. 버튼을 누를 때마다 횟수가 증가합니다.

실행 결과

버튼을 눌러 실행하세요.

예제 코드

let count = 0;
function handleClick() {
    count += 1;
    document.getElementById("result").textContent = "클릭 횟수: " + count;
}
document.getElementById("run").addEventListener("click", handleClick);
