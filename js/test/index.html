01. Git과 GitHub의 차이

  • Git: 파일 변경 이력과 버전을 관리하는 분산 버전 관리 시스템.
  • GitHub: Git 저장소를 온라인에 보관하고 협업하는 서비스.
  • Repository: 프로젝트 파일과 Git 기록을 담는 저장소.
  • Commit: 변경사항을 기록하는 이력 단위.
  • Branch: 독립적인 작업 흐름.
  • origin: 원격 저장소의 관례적인 이름.
  • main: 흔히 쓰이는 브랜치 이름. 프로젝트에 따라 다름.
VS Code에서 실행하기: 상단의 터미널 → 새 터미널을 연 후 명령어를 입력합니다. JavaScript 디버그 콘솔 또는 node >에는 입력하지 마세요.

02. GitHub 프로젝트 처음 가져오기

git --version
git clone https://github.com/baseballhub1/baseballhub1.github.io.git
cd baseballhub1.github.io
code .

git clone은 저장소 전체와 Git 기록을 복제하므로 git init은 필요 없습니다. cd와 code .은 Git 명령어가 아니라 터미널 및 VS Code 명령어입니다.

03. 새 프로젝트를 GitHub에 연결하기

Git 이력이 없는 로컬 프로젝트에 사용합니다. 먼저 GitHub에 빈 원격 저장소를 만들고 URL을 교체하세요.

git init
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git add .
git commit -m "첫 커밋"
git push -u origin main
원격 저장소에 이미 커밋이 있으면 푸시가 거절될 수 있습니다. 기존 GitHub 저장소를 내려받는 목적이라면 위 순서 대신 git clone을 사용하세요.

04. 평소에 사용하는 순서

최신 내용 가져오기

git status
git pull origin main

pull은 원격 변경사항을 가져와 현재 브랜치에 통합합니다. 로컬 변경사항과 충돌할 수 있습니다.

내 수정사항 업로드

git status
git add .
git commit -m "기능 수정"
git push

처음 푸시하는 브랜치라면 git push -u origin main처럼 업스트림 설정이 필요할 수 있습니다.

06. 브랜치로 작업하기

git switch -c feature/login
# 파일 수정 후
git add .
git commit -m "로그인 기능 작성"
git switch main
git merge feature/login
git push origin main

협업할 때는 기능 브랜치를 원격에 푸시하고 GitHub에서 Pull Request로 리뷰·병합할 수도 있습니다.

07. 자주 발생하는 오류

fatal: not a git repository

현재 위치가 Git 저장소가 아닙니다. git clone으로 받은 프로젝트 폴더로 cd하여 이동하세요. 기존 프로젝트를 받으려고 git init을 반복하지 마세요.

remote origin already exists

git remote -v
git remote set-url origin https://github.com/사용자명/저장소명.git

이미 등록된 origin의 주소를 확인하고, 주소 변경이 필요할 때만 set-url을 실행하세요.

nothing to commit, working tree clean

현재 커밋할 변경사항이 없다는 뜻입니다.

rejected (non-fast-forward)

원격과 로컬 커밋 이력이 달라 발생할 수 있습니다. 먼저 원격 변경을 확인하고 병합 또는 리베이스하세요. 이유 없이 git push --force를 실행하지 마세요.

Please tell me who you are

git config --global user.name "본인 이름"
git config --global user.email "본인 이메일"

CONFLICT

파일의 충돌 구간을 수정한 뒤 git add로 해결 상태를 표시하고 병합 절차를 완료합니다.

Authentication failed

접근 권한과 인증 설정을 확인하세요. GitHub는 HTTPS Git 인증에 계정 비밀번호 대신 자격 증명 관리자나 개인 액세스 토큰 등을 사용합니다.

Uncaught SyntaxError: Unexpected identifier 'pull'

JavaScript 실행 창에 Git 명령어를 입력한 경우입니다. VS Code 통합 터미널에서 실행하세요.
